## 1. 并行性总览（哪些能并行、哪些必须串行）

**三条互不依赖的轨道，可同时开工**：

| 轨道 | 阶段 | 工作区名（建议） | 提示词 | 依赖 |
| --- | --- | --- | --- | --- |
| 🅰 数据域 | 0 | `主线-研报复现-数据域` | Agent A | 无 |

**必须串行**：
- **数据 ingest 单写**：`0b`（指数回填）与任何其它 ingest 互斥，一次只一个 ingest 进程。

- **同一单点文件并发**：🅱 内 `emit.py`/`dsl.py` 由 1a/1b 两片合改，最后在一个工作区内**串行集成**。

**收口**：🅰、🅱、🅲 各自 push + PR 合入 `main`；阶段 2→5 在合入后新开工作区按序推进
（阶段 3 的 HRP / 去重 / 波动率 / 5 相位 4 子模块后续可再分 worker，本次先整体串行）。

### Agent B —— 算子域（阶段 1）

```text
你在 orca 工作树里工作，任务是为策略表达式 DSL 补算子地基，供「多资产 ETF 轮动」研报复现表达信号。
只做阶段 1，不碰数据契约/组合/指标。

【纪律（CLAUDE.md，强制）】同 Agent A（工作树只放代码、数据/runs/.venv 指回主检出、不 uv sync、
主检出环境跑测试、先清 UV_PROJECT_ENVIRONMENT/VIRTUAL_ENV、$env:PYTHONIOENCODING='utf-8'、证据追加 EVIDENCE.md）。
本轨道不做任何数据 ingest。

【背景】Expr DSL 在 src/quantlab/contract/emit.py（_SUPPORTED_OPS + evaluate()），当前 23 个算子，
无算术/log/exp，导致「0.70·rank(21)+0.30·rank(60)」「log(close/EMA)」「z-score」等复合得分无法表达。
新增算子必须同步 5 处：emit.py、x2/dsl.py、contract/lint.py、x2/paper2spec.py、
tests/test_p14_cross_sectional.py::test_whitelist_sync（锁 DSL_ALL_OPS == _SUPPORTED_OPS）。

【任务 1a —— 算术/数学算子】在 emit.py 加一等算子：add、sub、mul、div（二元算术）、neg（一元取负）、
log、exp（一元数学）。同步 dsl.py（DSL_ARITHMETIC_OPS/DSL_MATH_OPS + parse_dsl_node）、
paper2spec.py（OP_ALIASES）、白名单同步测试。这些是逐元素算子，无窗口，不涉及 lint 窗宽规则，
但 G4（叶子 shift≥1 因果）仍要扫它们的 field 子节点。

【任务 1b —— 专用窗口算子】在 emit.py 加一等窗口算子（numpy 直实现，全部因果/只用过去数据）：
- linreg_slope(window)、linreg_r2(window)：对 log(close) 做滚动 OLS 的斜率与拟合优度 R²。按 D1 用
  等权滚动最小二乘，docstring 显式标注「论文用时间加权回归，此处等权为近似」。
- llt(alpha)：低延迟趋势线（二阶滤波，α=0.10 场景），因果。
- zscore(window)：滚动 (x - mean)/std 标准化。
- ewm_std(span)：指数加权波动率（对收益率）。
同步 dsl.py、lint.py（把这些窗口算子加入 WINDOW_OPS，使 G5 lookback 覆盖、G6 窗口正整数扫到它们）、
paper2spec.py、白名单同步测试。

【测试】新增 tests/test_p15_operators.py（仿 tests/test_p14_cross_sectional.py，本地合成面板，离线）：
每个算子的语义、因果（未来扰动不改变过去输出）、窗宽校验、白名单同步。

【Gate】tests/test_p15_operators.py 绿；test_whitelist_sync 绿；全量 unittest discover 绿（508+）。

【产出】commit 回分支（末尾 Co-Authored-By: Claude Code <noreply@anthropic.com>），EVIDENCE.md 记录。不要 push。
```
